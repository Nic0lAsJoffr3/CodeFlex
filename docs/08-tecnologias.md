# Tecnologias Utilizadas

## Introdução

Este documento apresenta as tecnologias previstas para o desenvolvimento do **CodeFlex**, bem como a finalidade de cada uma dentro do projeto.

As tecnologias poderão ser alteradas durante o desenvolvimento caso sejam identificadas alternativas mais adequadas.

---

# Front-end

| Tecnologia | Finalidade |
|------------|------------|
| HTML5 | Estrutura das páginas da plataforma. |
| CSS3 | Estilização e responsividade da interface. |
| JavaScript (ES6+) | Lógica da aplicação e interação com o usuário. |

---

# Back-end

Inicialmente, o projeto utilizará os serviços disponibilizados pelo **Firebase**, dispensando a necessidade de um servidor próprio.

---

# Banco de Dados

| Tecnologia | Finalidade |
|------------|------------|
| Cloud Firestore | Armazenamento dos dados da plataforma. |
| Firebase Authentication | Gerenciamento da autenticação dos usuários. |
| Firebase Storage | Armazenamento de imagens, certificados e demais arquivos. |

---

# Hospedagem

| Tecnologia | Finalidade |
|------------|------------|
| GitHub Pages | Hospedagem da aplicação web. |

---

# Ferramentas de Desenvolvimento

| Ferramenta | Finalidade |
|------------|------------|
| Git | Controle de versão do projeto. |
| GitHub | Hospedagem do repositório e colaboração. |
| Visual Studio Code | Desenvolvimento do projeto. |

---

# Documentação

| Ferramenta | Finalidade |
|------------|------------|
| Markdown | Escrita da documentação do projeto. |
| Mermaid | Criação de diagramas. |

---

# Navegadores Compatíveis

A plataforma deverá oferecer suporte às versões recentes dos seguintes navegadores:

- Google Chrome
- Microsoft Edge
- Mozilla Firefox
- Opera
- Safari

---

# Tecnologias Futuras

Dependendo da evolução do projeto, poderão ser incorporadas novas tecnologias, como:

- Progressive Web App (PWA)
- Sistema de notificações
- Service Workers
- IndexedDB
- Inteligência Artificial aplicada ao ensino
- API pública do CodeFlex

---

# Observações

- As tecnologias listadas representam o planejamento inicial do projeto.
- Novas ferramentas poderão ser incorporadas durante o desenvolvimento conforme as necessidades da plataforma.
- Sempre que possível, serão priorizadas tecnologias gratuitas ou com planos gratuitos compatíveis com o objetivo educacional do projeto.
