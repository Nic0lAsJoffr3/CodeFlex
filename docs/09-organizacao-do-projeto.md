## TitleLogo.js

Responsável pela renderização e animação da logo principal do CodeFlex utilizando HTML Canvas.

### Responsabilidades

- Inicializar o Canvas utilizado pela logo.
- Obter as cores da identidade visual através das variáveis CSS.
- Renderizar os elementos da logo.
- Controlar a animação de entrada do texto.
- Animar os símbolos `<` e `>`.
- Atualizar a animação periodicamente.


## HeaderSvg.js

Responsável por carregar o arquivo SVG utilizado como elemento visual de fundo da Header da Pagina.

### Responsabilidades

- Carregar o arquivo `header.svg`.
- Obter o conteúdo do arquivo SVG.
- Inserir o SVG no elemento `.SVGBG`.
- Permitir que o SVG seja mantido em um arquivo separado do HTML.
